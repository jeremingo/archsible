# qmk

installs and sets up [qmk](https://docs.qmk.fm) using [my userspace](https://github.com/jeremingo/qmk_userspace).

- the [firmware](https://github.com/qmk/qmk_firmware) is cloned to *~/code/qmk/firmware*.
- my [userspace](https://github.com/jeremingo/qmk_userspace) is cloned to *~/code/qmk/userspace*.

### additional setup

- sets the default keymap to *jeremingo*, meaning only the keyboard should be specified when compiling/flashing with qmk.
